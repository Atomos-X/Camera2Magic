# Camera2Magic Magisk Module  
- [x] `c2m manager`: A manager responsible for selecting media and decoding services  
- [x] Built-in protective fallback image, used when no media is selected by the user  
- [x] A toggle switch to control whether to override the camera stream  
- [x] Custom images (videos)  
- [x] A new app icon to distinguish it from the LSP project  
- [x] Currently does not support raw10 format photo replacement; given potential use cases, it will not be supported in the future either :)  
  
**In development. Alpha-1 will be released soon. Join the Telegram channel to follow development progress and watch compatibility test videos.**
