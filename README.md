# Camera2Magic Magisk v0.1.79
  - 请勿将本项目继续视为虚拟摄像头模块:)
  - 本模块能够在运行 `不得不授权摄像头权限`才能正常使用的app，或意外启用app摄像头时保护您的隐私。
  - 从LSPosed模块移植的 `c2m manager`，一个UI app，能够控制是否使用隐私保护图案替换相机数据流。
  - 内置了一个默认的隐私保护图案，在演示视频中已经见到了。
  - 可以有限的自定义隐私保护图案？
  
**开发中，发布时间未定，访问仓库 `screenshots` 目录了解详情**
  
**测试机硬件信息：snapdragon 865（sm8250）/ LineageOS 23.2；`AOSP`/`LineageOS`以及基于它们的变种版本都能很好的工作，本人日常不用android设备，没有其他测试机，兼容性不作任何保证**

**任何非本仓库(fork)提供的`Camera2Magic`均与本人无关，任何利用本人代码以及预编译文件进行二次修改的行为本人毫不知情！！**

## 关于LSPOSED版Camera2Magic
  - 不提供任何预编译文件的源码，原因见下。
  - 请看issues置顶，如果某些功能没有，那就是设计如此。
